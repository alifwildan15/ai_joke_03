# ai-joke-03

One fixed one-liner about AI coding agents. Entry for make.fun's "ai-joke-03" bounty.

> My coding agent invented an API, called it, and then blamed it for being down.

The joke is fixed, so both runs write the same bytes.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only. The program writes the joke to `entry.txt` in the output directory (default `/output`).
